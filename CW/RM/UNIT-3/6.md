# Types of Measurement Scales

A **measurement scale** is a way of assigning numbers or labels to variables so that they can be analyzed. In research, four main types of measurement scales are used.

## 1. Nominal Scale (Classification Scale)

* Used to classify or label data into distinct categories.
* Numbers, if assigned, have no mathematical meaning.
* Categories are mutually exclusive.

### Examples

* Gender: Male, Female
* Blood Group: A, B, AB, O
* Religion: Hindu, Muslim, Christian, Sikh

### Characteristics

✔ Classification only

✔ No order or ranking

✔ Cannot perform arithmetic operations

**Example Question:**

> What is your preferred online payment method?
>
> * UPI
> * Credit Card
> * Debit Card
> * Cash on Delivery

---

## 2. Ordinal Scale (Ranking Scale)

* Data is arranged in a specific order or rank.
* The difference between ranks is not necessarily equal.

### Examples

* Class Rank: 1st, 2nd, 3rd
* Customer Satisfaction:
  * Very Satisfied
  * Satisfied
  * Neutral
  * Dissatisfied
  * Very Dissatisfied

### Characteristics

✔ Classification + Ranking

✔ Order exists

✘ Exact differences between ranks are unknown

**Example Question:**

> Rate the quality of the product:
>
> * Excellent
> * Good
> * Average
> * Poor

---

## 3. Interval Scale

* Has equal intervals between values.
* No true or absolute zero point.

### Examples

* Temperature in Celsius or Fahrenheit
* IQ Scores
* Calendar Years

### Characteristics

✔ Classification + Ranking

✔ Equal intervals

✘ No true zero

**Example:**

* Difference between 20°C and 30°C = 10°C
* Difference between 30°C and 40°C = 10°C

However,  **0°C does not mean absence of temperature** .

---

## 4. Ratio Scale

* Has all properties of the interval scale.
* Includes a true zero point.
* Allows meaningful comparisons like "twice as much."

### Examples

* Height
* Weight
* Age
* Income
* Number of Purchases

### Characteristics

✔ Classification

✔ Ranking

✔ Equal Intervals

✔ True Zero

**Example:**

* A person weighing 60 kg is twice as heavy as a person weighing 30 kg.
* Income of ₹40,000 is twice ₹20,000.

---

# Easy Memory Trick

### N-O-I-R

**N** = Nominal → Name/Category

**O** = Ordinal → Order/Rank

**I** = Interval → Equal Intervals

**R** = Ratio → Real Zero

# Measurement Scales: Exam Notes + Practice Questions

## Quick Revision Notes

### 1. Nominal Scale (Name/Categorize)

**Definition:** Used to classify data into different categories without any order.

**Examples:**

* Gender (Male/Female)
* Blood Group (A, B, AB, O)
* Religion
* Preferred Shopping App

**Key Features:**

* Classification only
* No ranking
* No mathematical calculations

**Remember:** Nominal = **Name**

---

### 2. Ordinal Scale (Order/Rank)

**Definition:** Data can be ranked or ordered, but the difference between ranks is not known.

**Examples:**

* Satisfaction Level
* Class Rank
* Service Quality Rating

**Key Features:**

* Classification + Ranking
* Distance between ranks unknown

**Remember:** Ordinal = **Order**

---

### 3. Interval Scale (Equal Intervals)

**Definition:** Values have equal intervals, but there is no true zero.

**Examples:**

* Temperature (°C, °F)
* IQ Scores
* Calendar Years

**Key Features:**

* Equal intervals
* No true zero
* Addition and subtraction possible

**Remember:** Interval = **Equal Distance**

---

### 4. Ratio Scale (Real Zero)

**Definition:** Has all characteristics of interval scale plus a true zero.

**Examples:**

* Age
* Height
* Weight
* Income
* Number of Purchases

**Key Features:**

* Equal intervals
* True zero exists
* All mathematical operations possible

**Remember:** Ratio = **Real Zero**

# Solved Examples

### Example 1

Question: What is your blood group?

Answer: **Nominal Scale**

Reason: Only categories are provided.

---

### Example 2

Question: Rate your satisfaction level:

* Excellent
* Good
* Average
* Poor

Answer: **Ordinal Scale**

Reason: Responses can be ranked.

---

### Example 3

Question: What is today's temperature?

Answer: **Interval Scale**

Reason: Equal intervals but no true zero.

---

### Example 4

Question: How many online orders have you placed this month?

Answer: **Ratio Scale**

Reason: True zero exists (0 orders).

# Frequently Asked Exam Questions

### Q1. Differentiate between Nominal and Ordinal Scale.

| Nominal                 | Ordinal                     |
| ----------------------- | --------------------------- |
| Used for classification | Used for ranking            |
| No order                | Order exists                |
| Example: Gender         | Example: Satisfaction Level |

---

### Q2. Differentiate between Interval and Ratio Scale.

| Interval              | Ratio             |
| --------------------- | ----------------- |
| No true zero          | True zero exists  |
| Example: Temperature  | Example: Weight   |
| Ratios not meaningful | Ratios meaningful |

---

### Q3. Why is Likert Scale Ordinal?

Because responses have an order:

* Strongly Agree
* Agree
* Neutral
* Disagree
* Strongly Disagree

But the exact difference between "Agree" and "Strongly Agree" is unknown.

# 10-Mark Exam Answer (Ready to Write)

**Measurement scales are methods used to assign values to variables for research and analysis. The four types of measurement scales are Nominal, Ordinal, Interval, and Ratio. Nominal scale classifies data into categories. Ordinal scale classifies and ranks data. Interval scale has equal intervals but no true zero. Ratio scale has equal intervals and a true zero, allowing all mathematical operations. Examples include Gender (Nominal), Satisfaction Level (Ordinal), Temperature (Interval), and Income (Ratio). Understanding measurement scales helps researchers select appropriate statistical techniques and interpret data correctly.**

✅ **One-line revision before exam:**

**Nominal = Name, Ordinal = Order, Interval = Equal Distance, Ratio = Real Zero.**
