# Supervised Learning Algorithms

## What is Supervised Learning?

Supervised Learning is a type of Machine Learning in which the model learns from  **labeled data** .

* **Input (X):** Features or attributes
* **Output (Y):** Known target/class/value

The algorithm learns the relationship between X and Y and then predicts the output for new unseen data.

### Example

Suppose we have student data:

| Study Hours | Attendance (%) | Result |
| ----------- | -------------- | ------ |
| 2           | 60             | Fail   |
| 4           | 75             | Pass   |
| 6           | 85             | Pass   |
| 1           | 50             | Fail   |

The model learns the mapping:

Result=f(Study Hours,Attendance)Result = f(Study\ Hours, Attendance)
Then it predicts whether a new student will pass or fail.

# Types of Supervised Learning

## 1. Classification

Predicts a  **category or class label** .

### Examples

* Email → Spam or Not Spam
* ECG Signal → Normal or Abnormal
* Loan Application → Approved or Rejected
* Disease Diagnosis → Positive or Negative

### Output

Discrete values
